🕯️ What Is LookingGlass?

LookingGlass is a fan-made project that brings the dark fantasy world of American McGee's Alice back to life on modern computers. Instead of running the original game engine, LookingGlass uses a brand-new engine written in Rust, a modern programming language known for stability and speed. The result is a smoother, sharper and more comfortable way to revisit Wonderland.

This is a re-remaster: it takes the classic third-person action-adventure experience and rebuilds the way the game runs, while keeping the campaign you remember. Every one of the 39 visits in the full campaign is playable from start to finish. The project is open source, which means anyone can inspect, learn from and improve it.

🧰 Troubleshooting Tips

The game says it cannot find the game data. Re-open the guided setup and point it at the folder that contains your 2011 game data. Make sure you select the folder itself, not a single file inside it.

The window is the wrong size. Open the display options and pick the resolution that matches your monitor. A fullscreen toggle is available there too.

My controller is not responding. Unplug it, close the game, plug it back in, then start the game again. Also try a different USB port.

The game closes unexpectedly. This is an experimental preview, so occasional hiccups can happen. Make sure your graphics drivers are current, then try again.

Windows warns about the download. Because the project is community-made, Windows sometimes shows a general caution message. Compare what you downloaded with the files listed on the releases page before continuing.
